# Written content

Facebook page/group posts, Pantip reviews, blog/SEO articles, LINE OA broadcasts, X/Threads. Goal: copy that earns trust first, then the click.

## Steps

1. Identify channel, product(s), audience, and the link type (Shopee/Lazada affiliate link; TikTok Shop products sell inside TikTok only).
2. Pick the template below that matches the channel.
3. Write with **honest specifics**: real usage, real numbers (size, weight, minutes, price), one genuine downside. Specifics convert; vague praise reads as an ad.
4. Add disclosure near the link, plus a sub_id per channel (`modules/links-tracking.md`).
5. Lint the full text; fix every `high`.
6. Deliver the copy plus posting notes. Done when the copy is paste-ready with link placeholders `[LINK:<product>|<sub_id>]`.

## Templates

**Facebook post (page or group)**
- Line 1: hook sentence that stops the scroll (problem or result).
- 3–6 short lines: story → what changed → specifics.
- Pros (3) / cons (1) bullet list.
- Price + where to buy + `[LINK]` + disclosure.
- Groups: read group rules first; many ban links in posts → put the link in the first comment and say so in the post.

**Pantip review (กระทู้รีวิว)**
- Title: product + use case + honest framing ("ใช้มา 1 เดือน").
- Body: background, why bought, photos per step, results with time frame, cons, who it suits / doesn't suit.
- Disclosure at the top when there is any affiliate link or free product. Pantip enforces rules on undisclosed promotion: check the room's current rules before posting.

**Blog / SEO article**
- Types that rank and convert: "ซื้อ___ยี่ห้อไหนดี [ปี]", "___ vs ___", "รีวิว___ ใช้จริง", "___ ราคาไม่เกิน ___ บาท".
- Structure: short answer up top (the pick), comparison table, one section per product (who it's for, pros, cons, price, `[LINK]`), FAQ, disclosure.
- Target one main keyword per article; use the long-tail Thai phrasing buyers type.

**LINE OA broadcast**
- One offer per broadcast; 2–4 lines; image or rich message; one `[LINK]`.
- Time it with mega-sale or payday windows (`reference/platforms.md`). Over-broadcasting raises block rate.

**X / Threads**
- One-line hook + one specific + link. Thread format for list content.

## Output contract

```
Channel: <channel>
Copy: <paste-ready, with [LINK:product|sub_id] placeholders>
Disclosure: <line used>
Posting notes: <time, group rule check, image list, where the link goes>
Lint summary
```
